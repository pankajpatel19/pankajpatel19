## 📌 Featured Projects

### 🚀 1. StudyMate – AI-Powered Personal Learning Assistant
An event-driven AI personal learning platform built with Next.js, Prisma, PostgreSQL, Pinecone, AWS Bedrock, and Inngest background queues. Asynchronously processes multi-page PDFs into vector embeddings, generates automated quizzes, presentation decks (pptxgenjs), and visual concept maps (Mermaid.js).
- 🔗 **Repo**: https://github.com/pankajpatel19/StudyMate-AI-Powered-Personal-Learning-Assistant  

---

### 🤖 2. AI Gmail Assistant using MCP
An agentic AI email assistant leveraging Model Context Protocol (MCP) and Groq LLM architecture to enable natural language inbox automation. Integrated with Google OAuth2 and Gmail API, featuring Zod-validated tool handlers (`read_emails`, `search_emails`, `send_email`) and a multi-turn React chat interface.
- 🔗 **Repo**: https://github.com/pankajpatel19/AI-Gmail-Assistant-using-MCP  

---

### ⚡ 3. AI-Powered Codebase RAG Assistant
A full-stack RAG application allowing developers to chat with codebase repositories. Generates 1024-dimensional embeddings via Amazon Titan v2 indexed in Pinecone Cloud, featuring language-aware AST chunking (JS, Python, Java) and vector similarity search for sub-second context retrieval.
- 🔗 **Repo**: https://github.com/pankajpatel19/AI-Powered-Codebase-RAG-Assistant
